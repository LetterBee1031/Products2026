# 暗算課題（Mental Arithmetic Task）実装設計

## 1. 目的

認知負荷推定モデルの検証用タスクとして実施する。

被験者には暗算課題を実施してもらい、課題難易度による認知負荷の変化を確認する。

本課題では、

* 正答率
* 解答数
* 解答時間
* 生理指標

を取得する。

Paas尺度およびその他の主観評価は別機能として実装する。

---

## 2. 課題形式

画面中央に掛け算問題を表示する。

被験者は暗算によって解答を求め、InputFieldへ入力する。

### 使用する数値

* 6〜18の整数

### 問題形式

```text
a × b
```

例

```text
12 × 14
```

### 重複扱い

以下は同一問題として扱う。

```text
6 × 14
14 × 6
```

問題生成時は

```text
a <= b
```

のみ使用する。

---

## 3. 難易度定義

積の値によって難易度を分類する。

| 難易度    | 条件                |
| ------ | ----------------- |
| Low    | 80 ≤ a × b ≤ 108  |
| Medium | 126 ≤ a × b ≤ 192 |
| High   | 221 ≤ a × b ≤ 324 |

上記条件に該当しない問題は使用しない。

---

## 4. 実施時間

### デフォルト値

```text
120秒
```

### 設定方法

体験空間内の InputField から変更可能とする。

### 入力仕様

| 項目      | 内容                 |
| ------- | ------------------ |
| オブジェクト名 | DurationInputField |
| 単位      | 秒                  |
| デフォルト値  | 120                |
| 最小値     | 30                 |
| 最大値     | 600                |

不正な値が入力された場合は120秒を使用する。

---

## 5. ブロック構成

| ブロック    | 難易度    |
| ------- | ------ |
| Block 1 | Low    |
| Block 2 | Medium |
| Block 3 | High   |

ブロック順はランダム化可能とする。

各ブロックの実施時間は DurationInputField の設定値を使用する。

## 11. 問題生成仕様

### 条件

* a = 6〜18
* b = 6〜18
* a <= b

---

### 分類処理

```csharp
for (int a = 6; a <= 18; a++)
{
    for (int b = a; b <= 18; b++)
    {
        int product = a * b;

        if (product >= 80 && product <= 108)
        {
            AddProblem(a, b, "Low");
        }
        else if (product >= 126 && product <= 192)
        {
            AddProblem(a, b, "Medium");
        }
        else if (product >= 221 && product <= 324)
        {
            AddProblem(a, b, "High");
        }
    }
}
```

---

## 12. 問題提示ルール

* 実験開始時に問題リストをシャッフルする
* 同一問題を連続提示しない
* 問題リストを使い切った場合は再シャッフルする
* ブロック終了まで繰り返し出題する

---

## 13. 実装上の要件

* ブロック時間をInputFieldから取得する
* SubmitButtonで回答確定
* SkipButtonで問題スキップ
* ○×フィードバックを500ms表示
* 正解値は表示しない
* 問題切替時にInputFieldを自動クリアする
* ブロック終了時にログをCSV保存する
* 主観評価画面への遷移は別システムで処理する
