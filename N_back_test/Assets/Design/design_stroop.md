# Unity Stroop課題 実装指示

## 実装対象

Unityで実行できるようC#でstroop testを実装してください。  
場所：products2026/N_back_test/Assets/Scripts/    
対象はVR/PC両対応とし、まずはPCキーボード入力で動作確認できるようにしてください。    
コントローラーの入力にも対応してください．  

---

## 実装する条件

### 条件1：Congruent（一致条件）

文字の意味と表示色が一致する。

例：

- 「赤」を赤色で表示
- 「青」を青色で表示
- 「緑」を緑色で表示
- 「黄」を黄色で表示

### 条件2：Neutral（中立条件）

文字は常に `XXXX` とし、表示色だけを変える。

例：

- `XXXX` を赤色で表示
- `XXXX` を青色で表示
- `XXXX` を緑色で表示
- `XXXX` を黄色で表示

### 条件3：Incongruent（不一致条件）

文字の意味と表示色が必ず異なる。

例：

- 「赤」を青色で表示
- 「青」を緑色で表示
- 「緑」を黄色で表示
- 「黄」を赤色で表示

## 使用する色

以下の4色を使用してください。

- 赤
- 青
- 緑
- 黄

内部的には以下の対応を持たせてください。

| 表示名 | ボタン入力 | color |
|---|---|---|
| 赤 | A | (255, 0, 0) |
| 青 | B | (0, 0, 255) |
| 緑 | X | (0, 130, 0) |
| 黄 | Y | (255, 255, 0) |

## 実験構成

条件ごとにブロック化してください。

1試行ごとに条件をランダム化するのではなく、1ブロック内では同じ条件のみを提示します。

### ブロック構成

- Practice：各条件10試行ずつ
- Block 1：Congruent 30試行
- Rest：休憩
- Block 2：Neutral 30試行
- Rest：休憩
- Block 3：Incongruent 30試行

各ブロックは，それぞれボタンに紐づけて，任意のタイミングで実行できるようにしてください

---

## 1試行の流れ

各試行は以下の流れで進行してください。

1. Fixation表示
   - `+` を表示
   - 1000 ms

2. 刺激表示
   - Stroop刺激を表示
   - 400 ms

3. 回答受付
   - A / B / X / Y のいずれかで回答
   - 正答は「文字の意味」ではなく「表示色」
   - 空白画面を表示
   - 最大1100ms
   - 回答を受け付け次第次の状態へ移行

4. 回答記録
   - 正解なら `Correct`
   - 不正解なら `Wrong`
   - 時間切れなら `Timeout`
   - 正解数をカウントしておく

5. 結果表示
   - 出題数と正答数を表示
